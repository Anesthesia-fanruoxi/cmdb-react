## 🔍 技术分析

### React项目的HTTP请求方案

**不使用axios,而是使用:**
- Tauri HTTP插件 (`@tauri-apps/plugin-http`)
- 自定义封装的 `apiClient` (src/services/request.ts)

**优势:**
- ✅ 原生性能更好
- ✅ 与Tauri深度集成
- ✅ 支持大整数保护
- ✅ 自动token刷新

### React项目的加密方案

**不使用crypto-js,而是使用:**
- Rust原生AES-256-GCM加密 (src-tauri/src/crypto.rs)
- 基于硬件指纹的设备密钥 (src-tauri/src/device.rs)

**加密流程:**
```
前端 (TypeScript)
  ↓ Tauri IPC
Rust后端 (AES-256-GCM)
  ↓
设备密钥 (基于硬件指纹)
```

**优势:**
| 特性 | Rust方案 | crypto-js方案 |
|------|---------|--------------|
| 加密算法 | AES-256-GCM | AES-256-CBC |
| 密钥安全 | 硬件绑定 | 需存储/硬编码 |
| 性能 | 原生Rust,极快 | JavaScript,较慢 |
| 安全性 | 难以逆向 | 容易被逆向 |
| 认证加密 | ✅ GCM模式 | ❌ 需额外HMAC |
