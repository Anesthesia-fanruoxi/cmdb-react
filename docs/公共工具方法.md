## 一、弹框管理

### 1.1 弹框栈管理器 (dialogStackManager)

**文件路径：** `src/utils/dialogStack.ts`

**用途：** 管理多层弹框的 ESC 键响应，确保只有最顶层弹框响应 ESC 关闭

**API：**

```typescript
import { dialogStackManager } from '@/utils/dialogStack';

// 注册弹框（打开时调用）
dialogStackManager.push(dialogId: string);

// 移除弹框（关闭时调用）
dialogStackManager.pop(dialogId: string);

// 检查是否是最顶层弹框
dialogStackManager.isTop(dialogId: string): boolean;

// 获取栈大小
dialogStackManager.size(): number;
```

**使用示例：**

```typescript
useEffect(() => {
  const dialogId = 'my-dialog';
  
  if (!visible) {
    dialogStackManager.pop(dialogId);
    return;
  }
  
  dialogStackManager.push(dialogId);
  
  const handleKeyDown = (e: KeyboardEvent) => {
    if (e.key === 'Escape' && dialogStackManager.isTop(dialogId)) {
      onClose();
    }
  };
  
  window.addEventListener('keydown', handleKeyDown);
  return () => {
    window.removeEventListener('keydown', handleKeyDown);
    dialogStackManager.pop(dialogId);
  };
}, [visible, onClose]);
```

**已使用位置：**
- `src/pages/Assets/ProUpdate/components/RecordDetailDialog.tsx`
- `src/pages/Assets/ProUpdate/components/LogViewerDialog.tsx`

**文件路径：** `src/services/storage/`

**模块说明：**

| 模块 | 文件 | 说明 |


### 3.2 SSE 连接

**文件路径：** `src/services/sql/search.ts`

**说明：** 创建 Server-Sent Events 连接

```typescript
import { createSSEConnection } from '@/services/sql/search';

const controller = createSSEConnection(
  '/sql/apply/list',           // URL 路径
  (data) => {                  // 消息回调
    console.log('收到数据:', data);
  },
  (error) => {                 // 错误回调（可选）
    console.error('SSE 错误:', error);
  },
  () => {                      // 完成回调（可选）
    console.log('SSE 完成');
  }

// 关闭连接
controller.close();
```

- `VITE_SSE_BASE_URL` - SSE 服务地址（如 `https://api.hzbxhd.com/sse`）

### 7.4 文件下载（Tauri）

**说明：** 在 Tauri 环境中使用文件保存对话框，让用户选择保存位置

```typescript
// 检查是否在 Tauri 环境
const isTauri = '__TAURI__' in window;

if (isTauri) {
  // Tauri 环境：使用文件保存对话框
  const { save } = await import('@tauri-apps/plugin-dialog');
  const { writeFile } = await import('@tauri-apps/plugin-fs');
  
  const filePath = await save({
    defaultPath: 'filename.xlsx',
    filters: [{
      name: 'Excel 文件',
      extensions: ['xlsx']
    }]
  });
  
  if (filePath) {
    // 用户选择了保存位置
    const arrayBuffer = await blob.arrayBuffer();
    const uint8Array = new Uint8Array(arrayBuffer);
    await writeFile(filePath, uint8Array);
    
    // 显示成功提示，包含保存路径
    toast.success('导出成功');
    addMessage({
      type: 'success',
      title: '文件导出成功',
      content: `文件已保存到：${filePath}`,
    });
  }
} else {
  // Web 环境：使用浏览器下载
  const link = document.createElement('a');
  link.href = window.URL.createObjectURL(blob);
  link.download = 'filename.xlsx';
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
  window.URL.revokeObjectURL(link.href);
}
```

**依赖配置：**
- 前端依赖：`@tauri-apps/plugin-dialog`、`@tauri-apps/plugin-fs`
- Rust 依赖：`tauri-plugin-dialog = "2"`、`tauri-plugin-fs = "2"`
- 权限配置（`src-tauri/capabilities/default.json`）：
  - `dialog:default`
  - `dialog:allow-save`
  - `fs:default`
  - `fs:allow-write-file`

## 八、启动动画

### 8.1 启动流程 Hook

**文件路径：** `src/hooks/useStartupFlow.ts`

**说明：** 管理应用启动动画的场景切换

**场景类型：**
- `init` - 初始化（应用启动）
- `token` - Token 自动登录
- `credential` - 设备凭据自动登录
- `login` - 正常登录成功
- `clear` - 清除缓存
- `logout` - 退出登录

**使用示例：**

```typescript
import { useStartupFlow } from '@/hooks/useStartupFlow';

const { flowType, currentStep, startFlow } = useStartupFlow();

// 启动登录动画
await startFlow('login', [
  async () => { /* 步骤1 */ },
  async () => { /* 步骤2 */ },
  async () => { /* 步骤3 */ },
]);
```

## 九、开发规范

### 9.1 添加新的公共方法

1. 在对应的 `utils/` 或 `services/` 目录下创建文件
2. 导出清晰的 API
3. 添加 TypeScript 类型定义
4. 在本文档中记录使用方法

### 9.2 文件命名规范

- 工具函数：`src/utils/xxxUtils.ts`
- 服务接口：`src/services/xxx.ts`
- Hooks：`src/hooks/useXxx.ts`
- 组件：`src/components/Xxx/index.tsx`

### 9.3 代码规范

- 单个文件不超过 300 行（文档除外）
- 使用 TypeScript 类型定义
- 添加必要的注释
- 导出的函数添加 JSDoc 注释
