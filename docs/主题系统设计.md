# 多主题系统设计

## 概述

支持多个预设主题和自定义主题,用户可以选择喜欢的主题或导入自定义配色。

## 主题类型

### 1. 预设主题

| 主题名称 | 主题ID | 说明 |
|---------|--------|------|
| 柔和亮色 | `light` | 默认亮色主题,柔和灰白色 |
| 柔和暗色 | `dark` | 默认暗色主题,深灰蓝色 |
| 纯净白 | `pure-light` | 纯白背景,适合喜欢高亮度的用户 |
| 深邃黑 | `pure-dark` | 纯黑背景,适合 OLED 屏幕 |
| 海洋蓝 | `ocean-blue` | 蓝色调主题,清新专业 |
| 森林绿 | `forest-green` | 绿色调主题,护眼舒适 |
| 暮光紫 | `twilight-purple` | 紫色调主题,优雅神秘 |
| 暖阳橙 | `warm-orange` | 橙色调主题,温暖活力 |

### 2. 自定义主题

用户可以:
- 导入 JSON 格式的主题配置
- 在线调整颜色并保存
- 导出自己的主题配置

## 主题配置结构

```typescript
interface ThemeConfig {
  id: string;                    // 主题ID
  name: string;                  // 主题名称
  type: 'light' | 'dark';        // 基础类型(影响文字对比度)
  colors: {
    // 背景色
    bgColor: string;             // 主背景色
    bgSecondary: string;         // 次级背景
    bgHover: string;             // 悬停背景
    bgPage: string;              // 页面底色
    
    // 文字色
    textColor: string;           // 主文字
    textSecondary: string;       // 次级文字
    textMuted: string;           // 弱化文字
    
    // 边框色
    borderColor: string;         // 浅边框
    borderColorDark: string;     // 深边框
    
    // 功能色
    primaryColor: string;        // 主色调
    primaryHover: string;        // 主色调悬停
    dangerColor: string;         // 危险色
    dangerHover: string;         // 危险色悬停
    successColor: string;        // 成功色
    warningColor: string;        // 警告色
    infoColor: string;           // 信息色
  };
}
```

## 技术实现

### 动态应用主题

```typescript
function applyTheme(theme: ThemeConfig) {
  const root = document.documentElement;
  
  // 设置基础类型
  if (theme.type === 'dark') {
    root.classList.add('dark');
  } else {
    root.classList.remove('dark');
  }
  
  // 应用颜色变量
  Object.entries(theme.colors).forEach(([key, value]) => {
    const cssVar = key.replace(/([A-Z])/g, '-$1').toLowerCase();
    root.style.setProperty(`--${cssVar}`, value);
  });
}
```

### 主题导入/导出

```typescript
// 导出主题
function exportTheme(theme: ThemeConfig): string {
  return JSON.stringify(theme, null, 2);
}

// 导入主题
function importTheme(json: string): ThemeConfig {
  const theme = JSON.parse(json);
  // 验证主题格式
  validateTheme(theme);
  return theme;
}
```

## 用户体验

1. **快速切换**: 点击主题按钮即可切换,无需刷新
2. **实时预览**: 编辑主题时实时看到效果
3. **一键导入**: 支持从文件或剪贴板导入主题
4. **分享主题**: 导出 JSON 文件分享给其他用户
5. **主题市场**: 未来可以添加主题市场,用户上传分享主题

## 兼容性

- 保持向后兼容,旧的 `light`/`dark` 主题ID继续有效
- 自动迁移旧的主题设置到新系统
- 如果自定义主题格式错误,回退到默认主题
