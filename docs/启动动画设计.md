# 启动动画设计文档

## 概述

本文档描述应用启动过程中的动画场景设计，用于提供流畅的用户体验和明确的状态反馈。

---

## 场景1：初始化

### 触发条件
- 应用启动时无有效 Token
- 退出登录后跳转到登录页

### 动画步骤
| 步骤 | 显示文字 | 执行操作 |
|------|----------|----------|
| 1 | 初始化中... | 读取本地公共数据（主题、登录历史、最后登录用户） |
| 2 | 准备就绪 | - |

### 完成后
显示登录页面，用户名输入框自动填充最后登录用户

---

## 场景2：自动登录 - Token

### 触发条件
- 应用启动时检测到有效 Token

### 动画步骤
| 步骤 | 显示文字 | 执行操作 |
|------|----------|----------|
| 1 | 验证登录... | 验证 Token 有效性 |
| 2 | 加载菜单... | 获取用户菜单和权限 |
| 3 | 恢复工作区... | 恢复页面状态、标签页、用户偏好设置 |
| 4 | 准备就绪 | - |

### 完成后
跳转到上次访问的页面

---

## 场景3：自动登录 - 设备凭据

### 触发条件
- 用户在登录页点击"自动登录"按钮

### 动画步骤
| 步骤 | 显示文字 | 执行操作 |
|------|----------|----------|
| 1 | 验证凭据... | 调用 Rust 后端验证设备凭据 |
| 2 | 登录成功 | - |

| 4 | 恢复工作区... | 恢复页面状态（无内容则跳过） |
| 5 | 准备就绪 | - |

### 完成后
跳转到上次访问的页面，无历史则跳转首页

## 场景5：清除缓存

### 触发条件
- 用户点击"清除缓存"按钮

### 动画步骤
| 步骤 | 显示文字 | 执行操作 |
|------|----------|----------|
| 1 | 开始清除缓存... | - |
| 2 | 清除完成 | 清除当前用户的页面状态、标签页缓存 |
| 3 | 重新获取权限... | 重新获取用户菜单和权限 |
| 4 | 启动中... | - |

### 完成后
跳转到首页，页面状态已重置

---

## 退出登录

### 触发条件
- 用户点击"退出登录"按钮

### 处理流程
1. 保存当前用户状态和偏好设置
2. 调用后端退出接口
3. 清除本地 Token
4. 跳转到登录页

### 说明
退出登录不需要单独的动画，因为跳转到登录页后会自动触发**场景1：初始化**的动画流程。

## 技术实现要点

### 动画组件位置
- `src/App.tsx` - 主启动动画逻辑
- `src/pages/Login/index.tsx` - 登录页初始化动画

### 状态管理
- 使用 `flowType` 标识当前动画场景
- 使用 `currentStep` 标识当前步骤
- 动画完成后设置 `ready = true` 显示实际内容

### 数据存储
- 公共数据（主题、登录历史）：Rust 后端管理
- 用户数据（Token、偏好、状态）：前端 Storage 管理
