# 缓存永久解决方案实现

## 🎯 需求

1. **首次获取/手动刷新**: 元数据存储到文件
2. **切换项目**: 从文件读取,不存在则调用API
3. **切换数据库**: 从文件读取表列表,不存在则调用API

## ✅ 实现方案

### 架构设计

```
┌─────────────────────────────────────────────────────┐
│                  用户操作                            │
└──────────────┬──────────────────────────────────────┘
               │
               ↓
┌─────────────────────────────────────────────────────┐
│              内存缓存 (window)                       │
│  - 第一优先级                                        │
│  - 速度最快                                          │

               │ 缓存未命中
               ↓
┌─────────────────────────────────────────────────────┐
│           文件缓存 (states.dat)                      │
│  - 第二优先级                                        │

               │ 缓存未命中
               ↓
┌─────────────────────────────────────────────────────┐

│  - 获取后立即缓存                                    │
└─────────────────────────────────────────────────────┘
```

## 📋 实现细节

### 1. 项目切换 (handleProjectChange)

```typescript
handleProjectChange(project, tabId) {
  // 步骤1: 清空当前状态
  updateTab(tabId, { 
    project, 
    dbName: '', 
    dbList: [], 
    tableList: [] 
  });
  
  // 步骤2: 尝试从文件恢复
  const restored = await restoreMetadataFromStorage(project, userName);
  
  if (restored) {
    // ✅ 文件缓存存在
    // 从文件 → 内存 (window对象)
    const cachedDbList = getAllCachedDatabases();
    updateTab(tabId, { dbList: cachedDbList });
  } else {
    // ❌ 文件缓存不存在
    // 调用API → 缓存到内存 → 持久化到文件
    await fetchAndCacheMetadata(project, tabId);
  }
}
```

### 2. 数据库切换 (handleDbChange)

```typescript
handleDbChange(dbName, tabId) {
  // 步骤1: 从内存缓存读取
  let tableList = getDbTables(dbName);
  
  if (tableList.length > 0) {
    // ✅ 内存缓存命中
    updateTab(tabId, { dbName, tableList });
    return;
  }
  
  // 步骤2: 从文件缓存读取
  const cacheData = getSqlMetadata(userName, project);
  if (cacheData?.dbTables?.[dbName]) {
    tableList = cacheData.dbTables[dbName];
    
    // 恢复到内存
    cacheDbTables(dbName, tableList);
    updateTab(tabId, { dbName, tableList });
    return;
  }
  
  // 步骤3: 调用API获取
  const res = await getDatabases({ agent: project });
  
  // 从完整元数据中提取当前数据库
  const dbMetadata = res.data.metadata.databases.find(
    db => db.db_name === dbName
  );
  
  if (dbMetadata?.tables) {
    tableList = dbMetadata.tables.map(t => t.name);
    
    // 缓存到内存
    cacheDbTables(dbName, tableList);
    
    // 同时缓存字段和统计信息
    dbMetadata.tables.forEach(table => {
      cacheTableFields(table.name, table.columns);
      cacheTableStats(table.name, table.stats);
    });
    
    // 持久化到文件
    await persistMetadataToStorage(project, userName);
    
    updateTab(tabId, { dbName, tableList });
  }
}
```

**流程图:**
```
切换数据库
  ↓
内存缓存? ──Yes→ 显示表列表
  │
  No
  ↓
文件缓存? ──Yes→ 恢复到内存 → 显示表列表
  │
  No
  ↓
调用API
  ↓
提取当前数据库的元数据
  ↓
缓存到内存 (表列表+字段+统计)
  ↓
持久化到文件
  ↓
显示表列表
```

## 🔄 缓存更新策略

### 内存缓存更新

```typescript
// 数据库列表
cacheDatabases(['db1', 'db2', 'db3']);
// → window.sqlMetadataCache.databases = [...]

// 数据库→表映射
cacheDbTables('db1', ['table1', 'table2']);
// → window.sqlMetadataCache.dbTables['db1'] = [...]

// 表字段
cacheTableFields('table1', [...]);
// → window.sqlFieldSuggestions['table1'] = [...]

// 表统计
cacheTableStats('table1', { rowCount: 1000, ... });
// → window.sqlMetadataCache.tableStats['table1'] = {...}
```

### 文件缓存更新

```typescript
// 持久化到文件
await persistMetadataToStorage(project, userName);

// 内部实现:
const cacheData = {
  databases: window.sqlMetadataCache.databases,
  dbTables: window.sqlMetadataCache.dbTables,
  tableStats: window.sqlMetadataCache.tableStats,
  fields: window.sqlFieldSuggestions,
  timestamp: Date.now(),
  version: '1.0'
};

// 保存到文件: states.dat
await saveSqlMetadata(userName, project, cacheData);
```

## 🎯 优势

### 1. 性能优化

| 操作 | 修复前 | 修复后 |
|------|--------|--------|
| 首次切换项目 | API调用 | API调用 |
| 再次切换项目 | API调用 | 文件读取 (快10倍) |
| 首次切换数据库 | 内存读取 | 内存读取 |
| 切换到新数据库 | 显示空 ❌ | API调用 ✅ |

### 2. 用户体验

**修复前:**
```
用户: 切换到db3
系统: 显示"暂无表" ❌
用户: 点击刷新
系统: 显示表列表 ✅
```

**修复后:**
```
用户: 切换到db3
系统: 检测缓存 → 自动调用API → 显示表列表 ✅
```

### 3. 缓存完整性

**修复前:**
- 只缓存访问过的数据库
- 切换到新数据库会丢失

**修复后:**
- 首次获取时缓存所有数据库
- 切换到任何数据库都能显示
- 即使缓存不完整,也会自动补全
