# 启动动画实现步骤

## 概述

本文档基于《启动动画设计.md》和《存储设计.md》，详细说明启动动画的实现逻辑、前后端调用关系以及需要修改的文件。

## 一、实现逻辑

### 1.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        App.tsx                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              StartupScreen 组件                      │    │
│  │  - 显示启动动画                                      │    │
│  │  - 根据 flowType 显示不同场景                        │    │
│  │  - 根据 currentStep 显示当前步骤                     │    │
│  └─────────────────────────────────────────────────────┘    │
│                              ↓                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              实际页面内容                            │    │
│  │  - Login 登录页                                      │    │
│  │  - Home 主页                                         │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 场景状态定义

```typescript
type FlowType = 
  | 'none'           // 无动画
  | 'init'           // 场景1：初始化（所有启动必经）
  | 'token'          // 场景2：Token 自动登录（初始化后触发）
  | 'credential'     // 场景3：设备凭据自动登录
  | 'login'          // 场景4：正常登录
  | 'clear';         // 场景5：清除缓存

const FLOW_STEPS: Record<FlowType, string[]> = {
  none: [],
  init: ['初始化中', '准备就绪'],
  token: ['验证登录', '加载菜单', '恢复工作区', '准备就绪'],
  credential: ['验证凭据', '登录成功', '加载菜单', '恢复工作区', '准备就绪'],
  login: ['登录成功', '加载菜单', '恢复工作区', '准备就绪'],
  clear: ['开始清除缓存', '清除完成', '重新获取权限', '启动中'],
};
```

**动画执行逻辑：**
- 应用启动 → 播放 `init` 动画 → 初始化完成
- 初始化完成后检查 Token：
  - 有效 Token → 播放 `token` 动画 → 进入主页
  - 无 Token → 显示登录页
- 两个动画是**连续但独立**的，`init` 完成后才决定是否播放 `token`

## 二、前后端调用逻辑

### 2.1 场景1：初始化（所有启动的第一步）

**触发**：应用启动（无论有无 Token）/ 退出登录后

```
前端                                    Rust 后端
  │                                         │
  │  读取 app.dat 获取 defaultTheme         │
  │  (前端 storage 服务，设置界面主题)      │
  │                                         │
  │──── get_login_history() ───────────────→│
  │←─── ["admin", "test"] ─────────────────│
  │                                         │
  │──── get_last_user() ───────────────────→│
  │←─── "admin" ───────────────────────────│
  │                                         │
  ▼                                         │
初始化完成，检查 Token                       │
```

### 2.2 场景2：Token 自动登录

**触发**：初始化动画完成后，检测到有效 Token（独立的第二个动画）

```
前端                                    Rust 后端 / API 服务器
  │                                         │
  │  (init 动画已完成，开始 token 动画)     │
  │                                         │
  │  读取 tokens.dat 获取 token             │
  │  (前端 storage 服务)                    │
  │                                         │
  │──── GET /api/user/profile ─────────────→│ API
  │←─── 用户信息 + 权限 ───────────────────│
  │                                         │
  │──── GET /api/user/menus ───────────────→│ API
  │←─── 菜单列表 ──────────────────────────│
  │                                         │
  │  读取 states.dat[username]              │
  │  读取 preferences.dat[username]         │
  │  (前端 storage 服务)                    │
  │                                         │
  ▼                                         │
跳转到上次访问的页面                         │
```

### 2.3 场景3：设备凭据自动登录

**触发**：用户点击自动登录按钮

```
前端                                    Rust 后端 / API 服务器
  │                                         │
  │──── auto_login(username) ──────────────→│ Rust
  │     (读取 credentials.dat 验证)         │
  │←─── { success: true, token: "..." } ───│
  │                                         │
  │──── add_login_history(username) ───────→│ Rust
  │                                         │
  │──── GET /api/user/profile ─────────────→│ API
  │←─── 用户信息 + 权限 ───────────────────│
  │                                         │
  │──── GET /api/user/menus ───────────────→│ API
  │←─── 菜单列表 ──────────────────────────│
  │                                         │
  │  读取 states.dat[username]              │
  │  读取 preferences.dat[username]         │
  │                                         │
  ▼                                         │
跳转到上次访问的页面或首页                   │
```

### 2.4 场景4：正常登录

**触发**：双因子/密码登录成功

```
前端                                    Rust 后端 / API 服务器
  │                                         │
  │──── POST /api/auth/login ──────────────→│ API
  │←─── { token: "...", user_name: "..." } ─│
  │                                         │
  │──── add_login_history(username) ───────→│ Rust
  │                                         │
  │  保存 token 到 tokens.dat               │
  │  (如果勾选保存登录状态)                 │
  │                                         │
  │──── GET /api/user/profile ─────────────→│ API
  │──── GET /api/user/menus ───────────────→│ API
  │                                         │
  │  读取 states.dat[username]              │
  │  读取 preferences.dat[username]         │
  │                                         │
  ▼                                         │
跳转到上次访问的页面或首页                   │
```

### 2.5 场景5：清除缓存

**触发**：用户点击清除缓存

```
前端                                    Rust 后端 / API 服务器
  │                                         │
  │  清除 states.dat[username]              │
  │  清除 menuStore 缓存                    │
  │  清除 pageStateStore 缓存               │
  │                                         │
  │──── GET /api/user/profile ─────────────→│ API
  │──── GET /api/user/menus ───────────────→│ API
  │                                         │
  ▼                                         │
跳转到首页                                   │
```

### 2.6 退出登录

**无动画，直接执行**

```
前端                                    Rust 后端 / API 服务器
  │                                         │
  │  保存 states.dat[username]              │
  │  保存 preferences.dat[username]         │
  │                                         │
  │──── POST /api/auth/logout ─────────────→│ API
  │                                         │
  │  删除 tokens.dat                        │
  │  清空内存状态                           │
  │                                         │
  │──── window.location.href = '/login' ───→│
  │                                         │
  ▼                                         │
触发场景1：初始化                            │
```

## 四、实现步骤

### 第一步：创建启动动画组件

1. 创建 `src/components/StartupScreen/index.tsx`
2. 创建 `src/components/StartupScreen/style.css`
3. 实现动画显示逻辑

### 第二步：创建启动流程 Hook

1. 创建 `src/hooks/useStartupFlow.ts`
2. 封装场景切换、步骤执行逻辑
3. 提供 `startFlow(type)` 方法

### 第三步：重构 App.tsx

1. 引入 StartupScreen 组件
2. 引入 useStartupFlow Hook
3. 根据 flowType 显示启动动画或实际内容
4. 实现各场景的执行逻辑

### 第四步：修改登录页

1. 移除 `storageReady` 状态和 loading 界面
2. 登录成功后调用 `startFlow('login')` 或 `startFlow('credential')`
3. 动画完成后由 App.tsx 控制跳转

### 第五步：修改退出登录

1. 退出登录后直接跳转 `/login`
2. 登录页加载时自动触发 `startFlow('init')`

### 第六步：修改清除缓存

1. 点击清除缓存后调用 `startFlow('clear')`
2. 动画完成后跳转首页

**说明：**
- 无论有无 Token，启动第一步都是**初始化**（读取公共数据：主题、登录历史）
- 初始化完成后才检查 Token 决定下一步
- 退出登录和清除缓存最终都会回到初始化状态
