# 安全组接口文档

服务地址：`http://localhost:8080`

安全组 ID 和地域均从配置文件读取，接口无需传入。

---

## 1. 查询安全组规则

**GET** `/api/assets/securityGroup/list`

无需请求体。

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "security_group_id": "sg-bp1ade41j0tki5q7jd1a",
    "security_group_name": "my-sg",
    "region_id": "cn-hangzhou",
    "vpc_id": "vpc-bp1xxxxxxxxxx",
    "ingress_rules": [
      {
        "direction": "ingress",
        "ip_protocol": "tcp",
        "port_range": "80/80",
        "source_cidr_ip": "0.0.0.0/0",
        "dest_cidr_ip": "",
        "policy": "accept",
        "priority": 1,
        "description": "允许HTTP",
        "create_time": "2024-01-01T00:00:00Z"
      }
    ],
    "egress_rules": []
  }
}
```

---

## 2. 添加入站规则

**POST** `/api/assets/securityGroup/add`

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| ip_protocol | string | 是 | 协议：tcp / udp / icmp / all |
| port_range | string | 是 | 端口范围，如 `80/80`、`8080/8090`、`-1/-1`（all时填） |
| source_cidr_ip | string | 是 | 源IP段，如 `0.0.0.0/0` |
| policy | string | 否 | accept / drop，默认 accept |
| priority | string | 否 | 优先级 1-100，默认 1 |
| description | string | 否 | 规则描述 |

**请求示例**

```json
{
  "ip_protocol": "tcp",
  "port_range": "3306/3306",
  "source_cidr_ip": "192.168.1.0/24",
  "policy": "accept",
  "priority": "1",
  "description": "允许内网访问MySQL"
}
```

**响应示例**

```json
{
  "code": 200,
  "message": "success"
}
```

---

## 3. 修改入站规则

**POST** `/api/assets/securityGroup/update`

> 通过规则 ID 直接修改，规则 ID 可从查询接口返回的 `ingress_rules` 中获取（阿里云控制台也可查看）。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| security_group_rule_id | string | 是 | 规则ID |
| ip_protocol | string | 否 | 协议：tcp / udp / icmp / all |
| port_range | string | 否 | 端口范围 |
| source_cidr_ip | string | 否 | 源IP段 |
| policy | string | 否 | accept / drop |
| priority | string | 否 | 优先级 1-100 |
| description | string | 否 | 规则描述 |

**请求示例**

```json
{
  "security_group_rule_id": "sgr-bp1xxxxxxxxxx",
  "port_range": "3306/3306",
  "source_cidr_ip": "10.0.0.0/8",
  "description": "修改为允许10段访问"
}
```

**响应示例**

```json
{
  "code": 200,
  "message": "success"
}
```

---

## 4. 删除入站规则

**POST** `/api/assets/securityGroup/del`

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| security_group_rule_id | string | 是 | 规则ID |

**请求示例**

```json
{
  "security_group_rule_id": "sgr-bp1xxxxxxxxxx"
}
```

**响应示例**

```json
{
  "code": 200,
  "message": "success"
}
```

---

## 错误响应格式

```json
{
  "code": 400,
  "message": "security_group_rule_id 不能为空"
}
```

| code | 说明 |
|------|------|
| 400 | 请求参数错误 |
| 500 | 服务端错误（含阿里云 API 错误） |
