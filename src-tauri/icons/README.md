# 应用图标

本目录用于存放 Tauri 应用的图标文件。

## 所需图标文件

根据 `tauri.conf.json` 配置，需要以下图标文件：

| 文件名 | 尺寸 | 用途 |
|--------|------|------|
| `32x32.png` | 32x32 像素 | Windows 任务栏图标 |
| `128x128.png` | 128x128 像素 | 通用图标 |
| `128x128@2x.png` | 256x256 像素 | 高分辨率显示 |
| `icon.icns` | 多尺寸 | macOS 应用图标 |
| `icon.ico` | 多尺寸 | Windows 应用图标 |

## 生成图标

### 方法 1：使用 Tauri 图标生成工具

准备一个 1024x1024 像素的 PNG 源图标，然后运行：

```bash
npx tauri icon path/to/your-icon.png
```

这将自动生成所有所需的图标文件。

### 方法 2：手动创建

1. 使用图像编辑软件（如 Figma、Photoshop）创建 1024x1024 的源图标
2. 导出为各种尺寸的 PNG
3. 使用在线工具转换为 .ico 和 .icns 格式

## 临时图标

在正式图标准备好之前，可以使用 Tauri 默认图标或创建简单的占位图标。
